# Personal Portfolio

Hand-coded portfolio built with HTML, CSS and vanilla JavaScript. The hero is an interactive least-squares regression: drag a dot and the line refits live (arrow keys also move a focused dot).

## Deploy on GitHub Pages
1. Create a public repo and upload index.html, style.css, script.js, README.md.
2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. After a minute the site is live at https://your-username.github.io/repo-name/
4. Open the link in an incognito window to check it.
